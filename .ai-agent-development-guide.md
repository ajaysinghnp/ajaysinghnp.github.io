# AI Agent Development Guide

## Overview

This guide provides comprehensive development instructions for AI agents working with this Next.js project. It covers development workflows, coding standards, and best practices for ensuring code quality and productivity.

## Development Environment

### Prerequisites

**System Requirements:**

- Node.js 18+ (or use the provided Docker setup)
- pnpm 8+ (preferred package manager)
- TypeScript support in your AI agent
- GitHub account (for API access)

**Development Environment Setup:**

#### Option 1: Local Development

1. **Clone the repository**

   ```bash
   git clone <repository-url>
   cd <project-directory>
   ```

2. **Install dependencies**

   ```bash
   pnpm install
   ```

3. **Set up environment variables**

   ```bash
   # Copy example to actual .env file
   cp .env.example .env
   # Edit .env with your actual values
   ```

4. **Start development server**

   ```bash
   pnpm dev
   ```

#### Option 2: Docker Development

1. **Build and run with Docker**

   ```bash
   docker build -t ajaysingh-portfolio .
   docker run -p 3000:3000 ajaysingh-portfolio
   ```

2. **Or use Docker Compose**

   ```bash
   docker-compose up --build
   ```

## Coding Standards

### TypeScript Standards

**AI agents should follow these TypeScript standards:**

1. **Type Safety**
   - Use TypeScript strict mode
   - No `any` types allowed
   - Comprehensive type definitions
   - Runtime type guards where needed

2. **Naming Conventions**
   - Use `kebab-case` for file names
   - Use `PascalCase` for component names
   - Use `camelCase` for variables and functions
   - Use `UPPER_SNAKE_CASE` for constants

3. **Import Ordering**

   ```typescript
   // 1. Standard library imports
   // 2. Third-party library imports
   // 3. Local application imports
   // 4. Component-specific imports
   ```

### Component Standards

**AI agents should follow these component standards:**

1. **Component Structure**

   ```typescript
   interface ComponentProps {
     // Define props with proper types
   }

   export function ComponentName({ prop1, prop2 }: ComponentProps) {
     // Component implementation
   }
   ```

2. **Component Naming**
   - Use descriptive names
   - Use PascalCase for component names
   - Use meaningful prop names
   - Use proper TypeScript interfaces

3. **Component Props**
   - Define interfaces for props
   - Use optional props with default values
   - Use proper TypeScript types
   - Document prop types

### API Route Standards

**AI agents should follow these API route standards:**

1. **Route Structure**

   ```typescript
   // app/api/example/route.ts
   import { NextRequest, NextResponse } from "next/server";

   export async function GET(request: NextRequest) {
     const { searchParams } = new URL(request.url);
     const param = searchParams.get("param");

     // Handle request
     const data = await getData(param);

     return NextResponse.json(data);
   }
   ```

2. **Error Handling**
   - Implement proper error handling
   - Use try-catch blocks
   - Return appropriate error responses
   - Log errors appropriately

3. **Input Validation**
   - Validate all inputs
   - Sanitize data
   - Use proper validation libraries
   - Return validation errors

## Troubleshooting

**TypeScript Errors:**

- Run `pnpm typecheck` for detailed error messages
- Fix type annotations and interfaces
- Ensure proper type imports and exports

**Linting Issues:**

- Run `pnpm lint` to identify problems
- Follow ESLint rules and conventions
- Fix code style and formatting issues

**Build Failures:**

- Check console output for specific error messages
- Review build logs for detailed information
- Ensure all dependencies are properly installed

**Development Server Issues:**

- Try `pnpm dev --turbo` if available
- Check for port conflicts
- Verify environment configuration
